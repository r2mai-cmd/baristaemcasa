# Barista em Casa

MVP inicial do site **Barista em Casa**: métodos, receitas, calculadora de proporção e preparo guiado com timer.

## Rodar localmente

É um projeto estático, então não precisa de build.

Opções:

- Abra `index.html` diretamente no navegador; ou
- use qualquer servidor local, por exemplo `python3 -m http.server 8000`.

## Estrutura

- `index.html` — estrutura da aplicação
- `styles.css` — identidade visual e responsividade
- `app.js` — dados das receitas, seleção, calculadora e timer
